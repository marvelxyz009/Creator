# Series memory

Separate world truth, character belief, reader knowledge and planned future possibilities. Track event chronology separately from narration order. Maintain characters' position, injuries, resources, relationships and knowledge after each approved chapter.

Plan series → phase → arc → chapter → scene. Keep distant phases flexible and the active arc concrete. A seed records setup source span, proposed payoff, dependencies and disclosure state. Never mark a proposed payoff as an event that occurred.

Audit edited source against current approved canon. Report contradictions with source evidence, not mere preference. A passing report proposes canon_delta; the harness promotes it only when the matching source revision is approved. Revisions must trigger dependency invalidation instead of rewriting history invisibly.
